 대상 버전 : 1.7.2
 제작자명  : JuneSilver (프로그램 정보에 적힌 회사명)
 작성 근거 : 소스 코드(.cs / .csproj / .iss / ShellExt 폴더)를 직접 읽고 정리함

이 문서는 "프로그램을 만든 사람이 아니어도, 이 앱이 무엇이고
어디에 무엇이 있으며 문제가 생기면 어디를 봐야 하는지" 알 수 있도록
쉬운 말로 쓴 안내서입니다.


----------------------------------------------------------------
 1. 한 줄 요약
----------------------------------------------------------------
커피뷰어는 윈도우용 "읽기 전용 통합 뷰어"입니다.
소설(txt, epub), PDF, 만화(zip 묶음, 그림 파일)를 한 프로그램에서 열어
읽을 수 있고, 책장(서재) 기능과 소리 내어 읽어주기(낭독)를 갖추고 있습니다.
인터넷 연결 없이 내 컴퓨터 안에서만 동작합니다.


----------------------------------------------------------------
 2. 무엇을 열 수 있나 (지원 파일)
----------------------------------------------------------------
 .txt   텍스트 소설. 읽던 자리 기억, 글 수정/저장 가능
 .epub  전자책. 챕터별로 보여줌
 .pdf   PDF 문서. 윈도우에 들어있는 Edge 엔진(WebView2)의 PDF 뷰어를 씀
 .zip   내용물을 보고 자동 판단:
          - 그림이 많으면 → 만화로 열기
          - txt가 있으면 → 이름 순서(2화→10화)로 이어 붙여 소설로 열기
          - epub / pdf가 있으면 → 임시 폴더에 꺼내서 해당 뷰어로 열기
          - "1화.zip, 2화.zip ..."이 든 묶음 zip도 한 권처럼 이어서 보기
 .jpg .jpeg .png .gif .bmp .webp  그림 파일
          (하나를 열면 같은 폴더의 그림들을 같이 넘겨볼 수 있음.
           webp는 SkiaSharp 라이브러리가 해석, 움직이는 gif/webp도 재생)


----------------------------------------------------------------
 3. 주요 기능 (사용자 눈에 보이는 것)
----------------------------------------------------------------
[서재 (단축키 Ctrl+L)]
  - 폴더를 등록하면 그 안의 txt/epub/pdf/zip 책을 모아 보여줌
  - "제목 1화, 제목 2화..." 같은 이어지는 파일은 시리즈로 묶어 표시
  - 진행률, 마지막으로 연 시각 표시 / 제목 검색
  - 우클릭: 탐색기에서 보기, 목록에서 빼기, 휴지통으로 보내기, 진행도 지우기
  - 폴더를 창에 끌어다 놓으면 서재에 등록됨
  - 서재만의 색 테마, 글자 크기를 따로 정할 수 있음

[읽기 창]
  - 책마다 창이 따로 뜸. 이미 열린 책을 또 열면 새 창 대신 그 창을 앞으로 가져옴
  - 읽기 방식 3가지: 스크롤 / 페이지(화살표로 넘김) / 페이지 터치(화면 좌우 탭)
  - 테마 5가지: 라이트, 세피아, 눈 편한 초록, 다크, 블랙
  - 글꼴/글자 크기/여백 조절 (Ctrl+휠, Ctrl+ +/-/0 도 가능)
  - 몰입 모드(F11), 항상 위, 이미지 표시 켜고 끄기
  - 찾기(Ctrl+F) / 바꾸기(Ctrl+H)
  - 하단 "탐색 막대": 같은 폴더 파일 목록, 챕터/이미지 선택, 위치 막대
  - 책 끝에서 더 넘길 때: 다음/이전 파일로 이동, 처음으로 돌아가기 등을
    설정에서 고를 수 있음 ( ] 다음 파일, [ 이전 파일 키)
  - PDF 야간 모드(색 반전)

[자동 재생 (F5)]
  - 소설: 낭독(TTS). 윈도우에 설치된 음성으로 한 문장씩 읽음.
          인터넷을 쓰지 않으므로 읽는 글이 밖으로 나가지 않음
  - 만화: 슬라이드쇼(1/2/3/5/10초 간격)

[txt 챕터 나누기]
  - 자동 / 제목 형식으로만 / 글자 수로 / 나누지 않음 중 선택
  - 제목 형식: N화, N장, 제N부, Chapter N, 프롤로그·에필로그, 숫자로 시작하는 줄,
    또는 직접 정규식 입력

[기타]
  - 도움말(F1) : 사용법 창
  - 설정(Ctrl+,) : 글꼴, 크기, 여백, 낭독 속도/목소리, 읽기 방식 등
  - 파일 탐색기 우클릭 메뉴에 "커피뷰어로 열기" 추가 (설치 시 등록)


----------------------------------------------------------------
 4. 이 프로그램은 무엇으로 만들었나 (기술 요약)
----------------------------------------------------------------
 언어/틀     : C# + .NET 9 + Windows Forms (윈도우 전용 데스크톱 앱)
 외부 부품   : - WebView2  : epub 표시와 PDF 보기 (Edge 엔진)
               - SkiaSharp : webp 그림 읽기
               - System.Speech : 낭독(윈도우 음성 합성)
 설치 파일   : Inno Setup (CoffeeViewer.iss)
 우클릭 메뉴 : C++ 로 만든 작은 DLL (ShellExt 폴더) - Windows 11용
 배포 방식   : "self-contained 단일 exe" → 사용자 PC에 .NET이 없어도 실행됨
 설치 위치   : %LOCALAPPDATA%\Programs\CoffeeViewer (관리자 권한 없이 설치)
 PC 조건     : 64비트 윈도우. PDF/epub 표시에는 WebView2 런타임 필요
               (윈도우 10/11에는 보통 이미 들어 있음)

----------------------------------------------------------------

                      없으면 서재를 띄움

  Themes.cs           색 테마 5종의 색상 정의

[화면(창)]
  LibraryForm.cs      서재 창
  LibraryStore.cs     서재 데이터(등록 폴더, 책 목록, 읽던 위치) 저장 (library.json)
  SettingsForm.cs     설정 창
  HelpForm.cs         사용법 안내 창 (안내 문구가 이 파일 안에 글로 들어 있음)
  MainForm*.cs        읽기 창 본체. 크기가 커서 6개 파일로 나뉘어 있음:
     MainForm.cs          핵심: 메뉴, 파일 열기, txt/epub/PDF/만화 표시
     MainForm.Features.cs 서재 연동, 낭독, 몰입 모드, 끌어놓기, 우클릭 메뉴
     MainForm.Zip.cs      zip 내용 판별과 열기
     MainForm.Nav.cs      하단 탐색 막대 연동
     MainForm.Edge.cs     책 끝에서 다음/이전 파일로 넘기는 처리
     MainForm.Format.cs   서식 메뉴(자동 줄바꿈, 글꼴), 글자 크기 확대/축소
     MainForm.StatusBar.cs 하단 상태 표시줄

  ImageCanvas.cs      만화/그림을 그려주는 영역

  ToastLabel.cs       잠깐 떴다 사라지는 알림
  TapZone.cs          화면 좌우 탭 영역

[파일 해석]

  ImageSet.cs / ImageLoader.cs  zip·폴더 속 그림 읽기 (webp는 SkiaSharp)

 6. 사용자 PC에 저장되는 데이터 (문제 해결 시 가장 중요)
----------------------------------------------------------------
(1) 설정과 서재 기록
    위치 : %LOCALAPPDATA%\CoffeeViewer\
           (주소창에 위 경로를 그대로 붙여넣으면 열림)
      settings.json  화면/글꼴/낭독/읽기 방식 등 설정
      library.json   등록한 폴더, 책 목록, 읽던 위치와 진행률
    - 이 두 파일을 지우면 설정이 처음 상태로 돌아가고 서재가 비워집니다.
      (책 파일 자체는 지워지지 않습니다.)
    - 파일이 깨져도 앱이 멈추지 않고 기본값으로 시작하도록 만들어져 있습니다.
    - 다른 PC로 옮기려면 이 폴더를 복사하면 됩니다.
    - 시험용: 환경 변수 COFFEEVIEWER_DATA_DIR 에 폴더를 지정하면
      실제 설정을 건드리지 않고 다른 폴더에 저장하며 시험할 수 있습니다.

(2) 임시 폴더 (zip/epub을 열 때 잠깐 풀어두는 곳)
    위치 : %TEMP%\CoffeeViewerZip , %TEMP%\CoffeeViewerEpub
    - 용량이 걱정되면 지워도 됩니다. 다음에 열 때 다시 만들어집니다.

(3) 원본 책 파일
    - 읽기만 하는 것이 기본입니다. 사용자가 편집 메뉴의 "수정하기"를 켜고
      직접 저장했을 때만 원본이 바뀝니다.
      (zip 안에서 꺼낸 글은 원본 zip을 덮어쓰지 않고 "다른 이름으로"만 저장됩니다.)
    - 서재의 "휴지통으로 보내기"는 실제 파일을 휴지통으로 보냅니다.
      "목록에서 빼기"는 서재 기록만 지우고 파일은 그대로입니다.

 7. 새 버전을 만들어 배포하는 순서 (개발 PC 기준)
----------------------------------------------------------------
필요한 도구 : Visual Studio(.NET 9 SDK, C++ 빌드 도구), Windows SDK(makeappx),
             Inno Setup

 1) 버전 올리기
    CoffeeViewer.csproj 의 <Version> 과 CoffeeViewer.iss 의 MyAppVersion 을
    같은 숫자로 바꿉니다. (두 곳이 어긋나지 않게 주의)
 2) 앱 빌드 : dotnet publish -c Release
    → publish\CoffeeViewer.exe 하나로 만들어집니다.
    ※ 반드시 Release 로 빌드하세요. 필요한 보조 DLL을 exe 안에 묶는 설정이
      Release 에만 걸려 있습니다. 빠뜨리면 설치본에서 "DLL was not found"
      오류가 납니다 (과거에 실제로 겪은 문제).
 3) 우클릭 메뉴 부품 만들기 :
    powershell -ExecutionPolicy Bypass -File ShellExt\build.ps1
    → publish\ 에 CoffeeViewerShell.dll, .msix, Assets 가 만들어집니다.
 4) 설치 파일 만들기 : Inno Setup 으로 CoffeeViewer.iss 를 컴파일
    → installer\CoffeeViewer-Setup-버전.exe 완성
 5) 이 설치 파일을 사용자에게 배포합니다.

설치 프로그램이 하는 일:
  - 관리자 권한 없이 현재 사용자 전용으로 설치
  - 시작 메뉴 "커피뷰어" 폴더 + (선택) 바탕화면 아이콘 생성
  - 윈도우 "연결 프로그램" 목록과 파일 우클릭 메뉴("커피뷰어로 열기") 등록
  - Windows 11 에서는 새 우클릭 메뉴에 띄우기 위해 별도 등록을 하며,
    이때 관리자 권한 확인창(UAC)이 한 번 뜹니다. 사용자가 "아니요"를 누르면
    옛 방식 메뉴("추가 옵션 보기" 안쪽)로 대신 남습니다.
  - 제거는 "설정 > 앱" 에서 일반 프로그램처럼 가능

바꾸면 안 되는 것 (바꾸면 기존 설치본이 깨질 수 있음):
  - exe 파일 이름 CoffeeViewer.exe
  - 설치 프로그램의 AppId (CoffeeViewer.iss 안 GUID)
  - ShellExt 의 CLSID 값 (ContextMenu.cpp 와 AppxManifest.xml 에서 서로 같아야 함)


----------------------------------------------------------------
 8. 자주 생기는 문제와 확인할 곳
----------------------------------------------------------------
Q. 설치한 앱이 "DLL was not found" 오류를 낸다
   → Release 설정으로 빌드하지 않고 만든 경우입니다. 7번 2)항 참고.

Q. Windows 11 새 우클릭 메뉴에 "커피뷰어로 열기"가 안 보인다
   → 설치 중 UAC 창에서 "아니요"를 눌렀거나 등록이 실패한 경우입니다.
     "추가 옵션 보기" 안쪽에는 남아 있습니다. 재설치 후 UAC 에서 "예"를 누르세요.
     (원리는 CoffeeViewer.iss 의 RegisterShellPackage 주석에 자세히 적혀 있음)

Q. 서재 목록/진행률이 이상하다, 설정이 꼬였다
   → 6번의 %LOCALAPPDATA%\CoffeeViewer\ 에서 library.json / settings.json 을
     (백업 후) 지우면 초기 상태로 돌아갑니다.

Q. zip 이 열리지 않고 "손상"이라고 나온다
   → OneDrive "온라인 전용" 파일을 내려받지 못해 생기는 경우가 있습니다.
     파일을 "항상 이 장치에 유지"로 바꾸거나 다운로드 후 다시 여세요.
     (프로그램이 이 경우를 따로 감지해 안내 메시지를 줌)

Q. 낭독 소리가 안 나거나 이상하다
   → 윈도우에 한국어 음성이 설치되어 있어야 합니다.
     (설정 > 시간 및 언어 > 음성 에서 한국어 추가)
     영어 전용 음성은 한글을 못 읽어 목록에서 제외됩니다.

Q. epub/PDF 가 안 보이고 빈 화면이다
   → WebView2 런타임이 없는 PC 일 수 있습니다. Microsoft 에서
     "WebView2 Runtime" 을 설치하면 해결됩니다.

Q. 큰 txt/zip 을 열 때 오래 걸린다
   → 정상입니다. 진행 게이지가 표시되며 취소할 수 있습니다.


----------------------------------------------------------------
 9. 유지보수 시 알아두면 좋은 점
----------------------------------------------------------------
 - 기능을 고칠 때 해당 기능이 어느 파일에 있는지는 5번 "폴더/파일 지도"를
   먼저 보세요. 코드 곳곳에 한글 설명 주석이 상세히 달려 있어서,
   개발자에게 맡길 때 "파일 이름 + 하고 싶은 변화"만 전달하면 충분합니다.
 - 사용법 안내 문구(F1 창)는 HelpForm.cs 상단의 긴 글 한 덩어리입니다.
   기능을 바꾸면 이 글도 같이 고쳐야 사용자 안내가 맞습니다.
 - 새 설정 항목은 AppSettings.cs 에 추가하고 SettingsForm.cs 에 화면을 붙입니다.
 - 새로 읽을 수 있는 파일 형식을 늘리려면
     (a) MainForm.cs 의 파일 열기 분기와 파일 대화상자 필터,
     (b) LibraryStore.cs 의 BookExtensions,
     (c) CoffeeViewer.iss 의 확장자 등록 목록(레지스트리 줄 + ShellExtensions),
     (d) ShellExt\AppxManifest.xml 의 ItemType
   이 네 곳을 함께 손봐야 합니다.
 - 소스 폴더에 버전 관리(git)가 없습니다. 수정 전에 폴더 전체를 복사해
